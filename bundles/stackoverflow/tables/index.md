# BigQuery 表

* [徽章](badges.md) - 该表包含 Stack Overflow 上授予用户的徽章信息。
* [评论](comments.md) - 包含 Stack Overflow 数据集中所有对帖子发表的评论。
* [孤立的标签 Wiki 帖子](posts_orphaned_tag_wiki.md) - 充当已不存在或孤立标签的 wiki 条目的帖子。
* [帖子历史](post_history.md) - 记录 Stack Overflow 上与帖子相关的所有变更与事件的历史。
* [帖子链接](post_links.md) - 包含 Stack Overflow 上帖子之间链接的信息。
* [帖子回答](posts_answers.md) - 包含 Stack Overflow 的回答，包括其内容、评分和关联的元数据。
* [帖子版主提名](posts_moderator_nomination.md) - 包含 Stack Overflow 平台上与版主提名相关的帖子。
* [帖子标签 Wiki](posts_tag_wiki.md) - 与 Stack Overflow 上所用标签关联的详细 wiki 条目，提供超越基础标签描述的综合信息。
* [帖子标签 Wiki 摘要](posts_tag_wiki_excerpt.md) - 该表包含 Stack Overflow 标签 wiki 的摘要帖子。
* [Stack Overflow 帖子（已弃用）](stackoverflow_posts.md) - 包含 Stack Overflow 帖子的已弃用表。请改用 posts_answers 或 posts_questions 表。
* [Stack Overflow 帖子问题](posts_questions.md) - 包含 Stack Overflow 的全部问题帖子。
* [Stack Overflow 帖子 Wiki 占位](posts_wiki_placeholder.md) - Stack Overflow 数据集中各类 wiki 风格帖子的占位表。
* [Stack Overflow 权限 Wiki 帖子](posts_privilege_wiki.md) - 包含 Stack Overflow 权限 wiki 帖子的信息，详述用户能力与相应要求。
* [Stack Overflow 用户](users.md) - 包含 Stack Overflow 平台上注册用户的信息。
* [Stack Overflow 投票](votes.md) - 记录对 Stack Overflow 帖子投出的所有投票。
* [标签](tags.md) - 包含 Stack Overflow 上所用标签的信息，包括其名称和使用次数。
